# Independent arithmetic review

PASS for the exact source closure pinned by `attention_fp32_math_review.json` and `math_final001/manifest.json`. Reviewer `/root/native_core` did not implement these primitives or change their RTL, reference, tests, or evidence. Current sources and archived source snapshots match every recorded SHA256; packet and common-contract pins also match.

The ALU keeps exact add/sub integers in units of 2^-149, serially normalizes the full cancellation result, and uses guard/sticky bits plus retained divide remainder for ties-to-even packing. Normal/subnormal boundaries, signed zeros, underflow and overflow are consistent with the packet. The restoring divider has bounded finite nonzero normalization and 52 division steps. Responses retain identity/data/error under stall; reset cancels both arithmetic engines. The reviewed testbench checks identity, held responses, no extra responses, and reset during work and held response.

All 10,194 rational-oracle vectors were independently cross-checked against NumPy native binary32 ADD/MUL/DIV/SUB and signed integer conversion, including expected error detection. Directed cross products include signed zero, smallest/largest subnormal, min-normal, exact cancellation, half-ULP operands, overflow, NaN/Inf and divide-by-zero. Directed integer ties include 16,777,217 and 16,777,219. Seeded raw-word cases add finite exponent/sign coverage. No mismatch occurred.

All 257 ROM values match nearest binary32 values independently recomputed with 100-digit Decimal exp2 and adjacent-float midpoint checks. All 12,064 stored exponential vectors satisfy domain/error/cutoff policy; the largest measured relative error over [-80,0] is 4.523316030180524e-6. An independently recomputed conservative combined reduction/interpolation/rounding bound is 5.12850481611299e-6, below 1e-5. The strict x<-80 cutoff is distinct from x=-80; the tiny-tail absolute error is at most exp(-80). Positive finite and nonfinite values produce error; both signed zeros produce one.

The actual XSIM decoded log contains exactly one PASS and reports 10,194 ALU plus 12,064 EXP cases, two reset scenarios, and maximum waits of 512/1129 cycles. Every recorded exit is zero. Both strict lint logs are empty. Actual synthesis logs have exactly one OOC PASS each, no black boxes, and constrained 5ns timing summaries with zero setup/hold/pulse failing endpoints: ALU WNS 2.061ns, WHS 0.079ns; EXP WNS 1.559ns, WHS 0.079ns. Resource figures agree with the reports (ALU 3474 LUT/1128 FF/2 DSP; EXP 4832 LUT/1382 FF/2 DSP). DSP pipeline recommendations are advisory and do not invalidate these positive estimates.

Acceptance is limited to these arithmetic primitives and source-bound unplaced OOC estimates. External boundary hold paths are explicitly excluded in the reviewed Tcl. This is not routed timing, board execution, full Attention/ISA integration, or pretrained-model accuracy evidence. Existing exact-source simulations were audited rather than redundantly rerun. There are no blocking findings.
