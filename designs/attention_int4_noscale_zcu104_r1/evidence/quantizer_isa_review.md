## RTL findings

The 128-bit command record retains END0/MM2S1/S2MM2 and adds QUANTIZE3. QUANTIZE accepts only three distinct bank IDs below3, full-width element count1..256, zero local offset and zero AXI address; legality is checked before count narrowing or acquisition. Executor addressing starts internally at word0. No top-level compute command bypass exists. Encoder field placement agrees with generated controller decoding.

Controller requires all three banks free in both ownership directions. Source read role3, data write role4 and scale write role5 masks are acquired together and exact-edge acceptance precedes EXECUTE/engine-valid. Controller keeps acquired, issued and completed tracking separately; completion compares saved three-bank identity, outstanding issue, and current matching saved roles. Release uses saved role constants and clears tracking only after all requested releases are accepted. Duplicate/spurious/mismatched responses enter the inherited fail-stop path rather than granting a release. Normal engine-valid stays held in stalled EXECUTE according to the pinned v4 controller behavior. END drains pending commands.

Executor holds one accepted source read outstanding, waits for owner-routed response-valid, then consumes only the required four-lane FP32 elements under child input-ready. Thus no source response remains outstanding when output replay begins. Nibbles pack low-first into a zero-initialized128-bit word; partial final words have zero padding. Each full-strobe destination write is accepted before advancing; final data acceptance precedes scale word0 acceptance, which precedes child-response acceptance and executor completion. Scale occupies low16bits with zero upper112bits. Response identity/error are saved and stable in RESPOND until handshake. Native enables are accepted pulses gated by actual ready; stalled writes do not reach memory.

Nonfinite rows consume all requested inputs and read responses, emit no INT4/scale writes, then report clean error and release matching roles. Coordinated reset cancels controller, executor, child and native response pipelines. Illegal internal executor state does not certify completion; an unclean protocol/owner fault retains unresolved ownership for reset recovery. Native memory response owner/valid pipelines are preserved, with no removed read-pending counter reintroduced.
